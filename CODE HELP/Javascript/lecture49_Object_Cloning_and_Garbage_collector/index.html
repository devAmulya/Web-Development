1. Js Object is dynamic because we can change its property at runtime
  2. Object Cloning : directly equating only marks its reference to same object(reference type)
  3. We need to create it differently for cloning : three methods
  4. (a) spread operator - ... Ex: let dest = {...src};
  5. (b) assign method : let dest = object.assign({},src)
  6. We can clone multiple objects into one object by mentioning extra src
  7. (c) Through iteration(not recommended)
  8. Diff btw [] access of obj and '.' access of obj
  9. '.' literally uses given name as key while you can pass a variable holding key/value in []
  10. For deep copy(creates new nested objects), use : (i) let dest = structuredClone(src); (ii) let clone = cloneDeep(src);(used library 'lofash/cloneDeep')
  11. Garbage Collector : C/C++ has manual, while Java/JavaScript has automatic garbage organisation(used garbage collector)
  12. It frees memory occupied using 'new' keyword preventing memory leaks
  13. Works automatically and alltime in background
