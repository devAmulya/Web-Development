1. Temporal Dead Zone: let/const miss hoisting so when we try to access variable earlier than declared, it created a zone(btw access and declare) known as temporal dead zone
  2. Variable scope : global , function, block scope
  3. Global Scope : anywhere in code(var,let,const)
  4. Function Scope : inside function only(var,let,const)
  5. Block scope: inside{} (only let and const - var can be accessed outside {} when defined inside)
