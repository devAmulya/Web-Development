1. Classes : blueprint, object : instance
  2. Class includs data member(state/Properties) and function(behaviour/functionality)
  3. instance of class is called class object
  4. Accessibility of class members :
  5. private(only inside defind class - (no object access)), access using this keyword inside class only
  6. Note : "this" keyword : refers to object that currently executing function/code and access its value(public, private, protected)
  7. Object can only access private when class has this keyword used.
  8. public(anywhere through objects without restrictions),
  9. protected(defined class and its child class)
  10. Getters and Setters used to access private variables in objects(used this keyword)
  11. Getters : get function where we access value of private. NO bracket when called
  12. Setters : set function which alllows to modiefy value of private
  13. Constructors : Defined inside class and Used to set value in class(like parameters in function)
  14. Ex : constructor(parameters) { this.parameter1 = variable; ....}
  15. Default Parameters : Given to functions
  16. Give value to parameters when defining in the function
  17. ANy sort of value can be given as default values(arrays, function, function-call,etc)
  18. If value passed is undefined by nature or absolute, function used default value to replace
