1. Error : Event which impact normal flow of execution
  2. Two types of error :
  3. =>compile-time(parser helps) ex syntax error
  4. =>Run-time(error handling) ex reference error
  5. Error Handling : use of try catch block
  6. try : attempts to run code
  7. catch : if code generates error while running, cames out of try block , catches error and run alternate code afterward
  8. =>variable defined inside() [err] stores error name and message
  9. finally block : always run even if error generates in try block
  10. =>always needs a try block
  11. throw : creates a custom error(as you see in system error) For example : Error 401
  12. => used inside try/catch block(send msg for error caught in catch block)
  13. =>They are uncaught errors and created using new keyword
